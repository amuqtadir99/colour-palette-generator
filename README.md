# 🎨 Colour Palette Generator

## 📌 Overview
The **Colour Palette Generator** is a simple web-based tool that generates beautiful colour palettes with **HEX** and **HSL** values. Users can generate a new palette, copy colour codes, and download the colour palette as a structured text file.

## 🚀 Features
✅ **Generate Random Colour Palettes** – Generates five colours at a time, using HSL-based generation for aesthetically pleasing results.  
✅ **HEX & HSL Values Displayed** – Each colour card clearly shows its **HEX** and **HSL** code.  
✅ **Copy to Clipboard** – Click on any colour card to instantly copy its HEX & HSL values.  
✅ **Download as Text File** – Save your colour palette as a structured text file for later use.  
✅ **Mobile-Friendly & Responsive UI** – Fully optimized for desktop and mobile devices.

## 🛠️ Setup & Usage
### 1️⃣ Open in a Browser
Simply open `index.html` in your browser, and the app will generate a new colour palette automatically.

### 2️⃣ Generate a New Palette
Click the **"Generate Palette"** button to get a fresh set of colours.

### 3️⃣ Copy Colours to Clipboard
Click on any colour card to copy its **HEX** and **HSL** value.

### 4️⃣ Download Palette
Click the **"Download Palette"** button to save the colour values in a structured `.txt` file.
